# mt5_flo

mT5-small ajustado con los pares de `data/interim/borrador_entrenamiento.csv` (8 épocas, `idea_flo/entrenar_mt5.py`).

En git se suben `config.json`, `generation_config.json`, `tokenizer_config.json` y `tokenizer.json`.
Los pesos (`model.safetensors`, 1,2 GB) **no están en git**: se comparten por separado (Drive). Para usar el modelo, copiarlos a esta carpeta.
